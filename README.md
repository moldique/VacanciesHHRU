# Проект "Парсинг вакансий с hh.ru"

## Описание:

Получение информации о вакансиях и сохранение в JSON.
## Установка:

1. Клонируйте репозиторий:
```
https://github.com/moldique/VacanciesHHRU
```

2. Установите зависимости:
```
pip install -r requirements.txt

```
## Технологии:

1. python 3.13
2. dotenv
3. requests
4. json

## Использование:

Для запуска программы выполните следующую команду в терминале:
```
python main.py
```

Программа будет работать в цикле, пока вы не захотите выйти из нее.
